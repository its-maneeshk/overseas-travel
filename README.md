# 🌍 Overseas Travel & Medical Assistance Portal

A modern, responsive, and zero-cost web application built with **Next.js 16 (App Router)**, **TypeScript**, **Tailwind CSS (v4)**, and **Supabase**. Designed specifically to connect international clients with curated Himalayan treks, cultural tours, holistic wellness retreats, and accredited medical assistance programs in Nepal.

---

## 🚀 Key Features

* **Dynamic Public Catalog:** Browse live travel and medical packages fetched securely from Supabase.
* **Protected Admin Portal** A custom, user-friendly CRUD form allowing administrators to publish, edit, and manage tour packages without touching code.
* **Direct WhatsApp Integration:** Instant pre-filled inquiry buttons connecting prospective travelers directly with coordinators.
* **Dynamic SEO & OpenGraph Meta Tags:** Automated metadata generation for individual tour slugs (`/packages/[slug]`) ensuring rich preview cards when shared on WhatsApp and social media.
* **Zero-Cost Architecture:** Optimized to run 100% free on Vercel and Supabase free tiers, making it ideal for early-stage scaling.
